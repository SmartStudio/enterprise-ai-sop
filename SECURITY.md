# Security

This repository is documentation. It should never contain secrets, client prompts, or production architecture that identifies a customer.

## Do not file in public issues

- API keys, tokens, gateway configs with credentials
- Client names, internal URLs, or prompt logs
- Instructions for unofficial model relays that handle company data

Email security reports to contacts@fxai.ai. Do not open a public issue for a secret that already leaked into a PR.

## If you find a secret in git history

Assume it is burned. Rotate the credential, then email us the path and commit SHA. We will purge or revert after rotation.
